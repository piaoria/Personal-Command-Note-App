# 커맨드 노트

Windows에서 명령어와 상황별 작업 순서를 관리하는 개인용 Electron 앱입니다. 명령은 자동 실행하지 않고 복사만 합니다.

## 실행

1.3.2 실행 파일은 `release/1.3.2/win-unpacked/CommandNote.exe`, 설치 파일은 `release/1.3.2/CommandNote-1.3.2-setup.exe`입니다. 독립 실행판을 옮길 때는 win-unpacked 폴더 전체를 유지하세요. 실행판에는 개발 서버나 Node.js 설치가 필요하지 않습니다.

Windows 기본 제목 표시줄과 메뉴 바를 숨겼습니다. 앱 상단의 커맨드 노트 영역을 드래그해 창을 이동하고, 가장자리에서 크기를 조절할 수 있습니다. 오른쪽의 −는 최소화, ×는 트레이로 숨기기입니다. 노트를 불러오는 중에도 창 이동과 창 버튼을 사용할 수 있습니다.

창 닫기는 트레이로 숨기기입니다. 트레이 더블 클릭이나 전역 단축키로 열고, 트레이 메뉴 또는 앱의 자료 관리에서 **완전 종료**할 수 있습니다. 최소화는 작업 표시줄로 이동합니다. Esc는 편집 취소·뒤로 가기를 먼저 처리한 뒤 트레이로 숨깁니다.

## 제공 기능

- 명령어, 화면 조작, 작업 순서, 오류 해결의 네 유형
- 도구·태그·실행 환경·입력 위치·위험도 편집
- 옵션 설명, 결과 읽는 법과 주의점 작성
- 변수 값을 입력해 PowerShell 또는 Bash 명령 복사
- 작업 단계 추가·순서 변경·명령어 카드 연결, 연결된 작업으로 돌아가기
- 전체·즐겨찾기·최근 항목 보기, 도구·유형 필터와 검색
- 보관함·휴지통 이동과 복구. UUID와 카드 참조 유지
- 단일 문서 또는 사용 중인 노트의 Markdown 가져오기·내보내기
- 전체 ZIP 백업·검토 후 복원
- 트레이, 전역 호출 단축키, 항상 위 고정, 다크 모드
- 라이트 모드의 컬러 도구 SVG와 다크 모드의 회색 도구 SVG
- Windows 창 전체 불투명도 조절과 재실행 시 설정 복원
- 검색창 중심의 심플 모드와 기존 확장 모드 전환, 마지막 모드 저장
- 변수 입력 전용 빠른 복사 폼, 명령 템플릿에서 입력 항목 추출
- 전역 창 호출·모드 전환 단축키와 검색창의 앱 명령

도구 아이콘은 Docker, Git, GitHub, MongoDB, MongoDB Compass, MobaXterm, PowerShell, Bash, NoSQL Workbench, VS Code를 지원합니다. 서비스의 식별 형태를 참고해 직접 그린 로컬 SVG이며, 목록·상세·연결 카드·도구 입력란에서 사용합니다. 사용자 지정 분류에는 기본 아이콘을 표시합니다. 참고: [Docker](https://www.docker.com/company/newsroom/media-resources/), [Git](https://git-scm.com/community/logos), [MongoDB](https://www.mongodb.com/company/newsroom/brand-resources), [MobaXterm](https://mobaxterm.mobatek.net/), [PowerShell](https://github.com/PowerShell/PowerShell/tree/master/assets), [Bash](https://www.gnu.org/software/bash/), [NoSQL Workbench](https://aws.amazon.com/dynamodb/nosql-workbench/).

상단 **창 불투명도**는 40–100% 범위에서 창 전체에 적용됩니다. 낮추면 글자와 아이콘을 포함해 뒤의 화면이 비칩니다. 기존의 패널 배경 알파가 같은 색의 불투명 배경과 겹치던 문제를 해결했습니다. 웹 미리보기는 패널 배경만 바뀌므로 실제 효과는 Windows 실행판에서 확인하세요.

## 심플 모드

확장 화면 상단의 **안쪽 화살표 아이콘**을 누르면 검색창만 남는 작은 창으로 전환합니다. 심플 화면의 **바깥쪽 화살표 아이콘**으로 확장 화면에 돌아갑니다. 버튼에는 글자 대신 아이콘만 표시하고, 마우스를 올리면 동작과 단축키를 보여 줍니다. 두 화면 모두 **핀 아이콘**으로 항상 위 고정을 켜고 끌 수 있으며, 고정 중에는 버튼이 강조됩니다.

검색하면 사용 중인 노트에서 최대 6개 결과를 보여 주고 창 높이를 맞춥니다. 검색창 위 손잡이를 드래그해 창을 이동할 수 있습니다. 필터·즐겨찾기 관리·노트 작성·자료 관리는 **확장 모드**에서 이용합니다.

- ↑ / ↓: 결과 선택
- Enter: 선택한 카드 열기
- Ctrl+Enter: 명령 복사. 변수 입력이나 작업 순서 확인이 필요한 항목은 카드를 엽니다.
- Esc: 검색어를 먼저 지우고, 빈 검색창에서는 트레이로 숨기기

카드를 열면 상세 화면으로 확장되고, 돌아가면 심플 검색으로 복귀합니다. 마지막으로 선택한 모드는 저장되며 전역 단축키로 다시 불러올 때도 적용됩니다. 편집 중인 초안이 있으면 단축키로 호출해도 초안을 유지합니다. 노트 편집 중에는 모드 전환 버튼을 사용할 수 없습니다.

## 서비스 아이콘

민트색의 둥근 바탕, 크림색 메모 카드, 터미널 기호와 작은 미소를 조합한 아이콘입니다. `>`와 `_`를 같은 눈높이에 두고 가운데 아래에 웃는 입을 배치해 이모티콘처럼 표현합니다. 앱 상단과 심플 검색창은 다크 모드에서 회색으로 표시합니다. Windows 실행 파일·설치·제거 프로그램과 트레이에도 전용 아이콘을 사용합니다.

- SVG 원본: `public/brand/commandnote.svg`
- 512px PNG: `public/brand/commandnote.png`
- Windows ICO: `resources/commandnote.ico` (16·24·32·48·64·128·256px)
- 작은 트레이용 원본: `public/brand/tray.svg`
- 크기·테마 미리보기: `public/brand/preview.png`

이미지를 다시 변환하려면 Sharp가 설치된 Node 도구 환경에서 `node scripts/generate-icons.cjs`를 실행합니다. 프로젝트 외부에 설치되어 있다면 `COMMAND_NOTE_IMAGE_MODULES`에 해당 node_modules 폴더를 지정합니다. 변환 도구는 앱을 실행하지 않으며, Sharp는 앱의 실행 의존성에 포함되지 않습니다.

## 명령 변수

편집 화면에서 변수 이름과 설명을 추가하고 명령에 `docker inspect {{container}}`처럼 작성합니다. 상세 화면에서 값을 입력한 뒤 완성된 명령을 복사합니다. 값은 파일에 저장하지 않습니다.

명령에 `{{container}}`, `{{lines}}`를 작성한 뒤 **명령에서 변수 가져오기**를 누르면 입력 항목이 자동으로 추가됩니다. 이미 작성한 변수의 설명과 필수 여부는 유지합니다. 셸은 PowerShell 또는 Bash로 선택하세요.

```text
docker logs --tail {{lines}} {{container}}
```

이 노트의 복사 버튼을 누르거나 심플 검색에서 선택하면 값 입력 폼이 열립니다. 예를 들어 `lines = 100`, `container = my-api`를 입력하면 `docker logs --tail '100' 'my-api'`를 미리 보고 **Enter**로 바로 복사합니다. 심플 모드에서는 입력 폼도 작은 창으로 유지하고, 복사 후 검색창으로 돌아갑니다. 복사 실패 시 입력값을 보존합니다. 필수값이 비었거나 템플릿이 잘못되면 복사하지 않습니다.

PowerShell 또는 Bash를 선택해야 하며, `{{container}}`는 따옴표 없이 독립된 인수로 둡니다. 공백과 작은따옴표는 셸별로 인용합니다. 문자열 안에 끼워 넣는 변수, 줄바꿈이 있는 입력과 등록되지 않은 변수는 복사하지 않습니다. Docker의 `{{json .Mounts}}` 같은 Go 템플릿은 그대로 보존합니다.

작업 단계에는 기존 카드를 연결하거나 설명만 작성할 수 있습니다. 연결된 카드를 편집하면 작업에서도 최신 내용이 표시됩니다. 보관·삭제한 카드는 작업 단계에 상태가 표시되며, 카드를 열어 복구할 수 있습니다.

## 자료 관리

**Markdown 가져오기**는 `.md` 파일을 한 번에 200개까지 선택합니다. 커맨드 노트 문서는 환경·변수·작업 단계까지 읽습니다. 일반 Markdown은 제목과 첫 코드 블록을 바탕으로 새 노트를 만들고 원문을 설명에 보존합니다. 기존 ID와 겹치면 사본을 만들며, 함께 가져온 카드 간 연결도 새 ID로 바꿉니다. 파일 하나는 1MB 이하여야 합니다.

**Markdown 내보내기**는 상세 화면의 개별 문서 또는 자료 관리의 사용 중인 노트 내보내기에서 실행합니다. 작업 순서를 내보내면 연결된 카드도 포함합니다. 여러 파일은 선택한 폴더 안의 새 하위 폴더에 저장합니다.

**ZIP 백업**에는 사용 중인 노트, 보관함과 휴지통, 카드 연결, 즐겨찾기와 최근 기록이 포함됩니다. 복원은 파일을 검증하고 문서 개수를 표시한 뒤 사용자가 확인하면 현재 자료 전체를 교체합니다. 복원 전 자료는 vault 상위의 `vault-before-restore-<UUID>` 폴더에 보존합니다. PC별 외형·단축키 설정은 유지합니다. 최대 2000개 문서와 전체 50MB를 지원하며 손상되거나 누락된 참조가 있는 백업은 복원하지 않습니다.

## 저장 위치와 호환성

- 독립 실행판과 설치판: `%APPDATA%\CommandNote\vault`
- 개발판: `%APPDATA%\CommandNote-dev\vault`
- 웹 미리보기: 브라우저 IndexedDB, Windows 앱과 별도 저장

앱 하단의 저장 폴더에서 실제 경로를 확인할 수 있습니다. 문서는 `notes/<UUID>.md`, 즐겨찾기와 최근 기록은 `library-state.json`에 저장합니다. 보관과 삭제는 복구할 수 있는 상태 변경이며 원본 문서를 지우지 않습니다. 수정 전 복구본은 `backups`에 둡니다.

기존 버전 1 문서는 읽을 때 버전 2 모델로 변환하고, 실제 편집·저장 시에만 버전 2 파일로 기록합니다. UUID, 원문과 기존 추가 메타데이터는 유지합니다. 알 수 없는 미래 버전과 읽을 수 없는 문서는 원본을 보존하고 오류를 표시합니다.

## 전역 단축키

| 단축키 | 동작 |
| --- | --- |
| **Ctrl+Alt+K** | 창 열기·검색. 창이 맨 앞에 있으면 트레이로 숨기기 |
| **Ctrl+Alt+M** | Windows의 다른 앱에서 창을 열고 심플·확장 모드 전환 |
| **Ctrl+Shift+M** | 앱 안에서 심플·확장 모드 전환 |
| **Ctrl+K** | 앱 안에서 검색창으로 이동 |

CommandNote가 실행 중이거나 트레이에 있을 때 전역 단축키가 작동합니다. **완전 종료**하면 등록도 해제됩니다. 편집 중인 초안이나 변수 입력이 있으면 그대로 보존하며, 작성·입력을 마친 뒤 모드를 바꿀 수 있습니다. 자료 관리에서 두 전역 단축키를 각각 바꾸거나 입력을 비우고 저장해 해제할 수 있습니다. 다른 앱 또는 앱의 다른 동작과 겹치는 조합은 기존 설정을 유지합니다. 기존 창 열기 단축키 설정도 유지합니다.

창이 숨겨졌거나 최소화됐거나 다른 앱 뒤에 있으면 Ctrl+Alt+K로 앞으로 가져옵니다. 같은 키를 다시 누르면 트레이로 숨기고, 트레이를 사용할 수 없는 환경에서는 최소화합니다. 트레이 메뉴와 더블 클릭은 창을 여는 동작을 유지합니다. 앱 안의 Ctrl+K와 Ctrl+Shift+M은 한글 입력 상태에서도 같은 물리 키로 작동합니다.

검색창에 `/`를 입력하면 앱 명령이 나타납니다. 방향키와 Enter 또는 클릭으로 선택합니다. 확장 모드의 검색창에서는 Enter로 첫 명령을 선택할 수 있습니다.

| 앱 명령 | 동작 |
| --- | --- |
| `/simple` 또는 `/심플` | 심플 모드 |
| `/expanded` 또는 `/확장` | 확장 모드 |
| `/toggle` 또는 `/전환` | 모드 전환 |
| `/hide` 또는 `/숨기기` | 트레이로 숨기기 |

앱 명령은 창 조작만 수행합니다. 저장한 셸 명령은 실행하지 않고 복사합니다.

## 소스에서 실행

Node.js 22.14 이상과 프로젝트가 선언한 pnpm 10.34.3을 사용합니다.

```powershell
pnpm install --frozen-lockfile
pnpm setup:desktop
pnpm dev:desktop
```

| 명령 | 용도 |
| --- | --- |
| `pnpm dev` | 기존 Figma 웹 미리보기 |
| `pnpm dev:desktop` | Electron 개발 실행 |
| `pnpm build:desktop` | 타입 검사와 Electron 빌드 |
| `pnpm preview:desktop` | 빌드한 화면을 Electron에서 실행 |
| `pnpm pack:desktop` | Windows 독립 실행 폴더 |
| `pnpm dist:win` | Windows 설치 파일 |
| `pnpm test` | 저장, 이관, 변수, 연결, 보관·복구와 백업 테스트 |
| `pnpm test:desktop` | 분리된 데이터로 실제 Electron 연결·트레이·단축키 초기화 검증 |

setup:desktop은 최초 설치 때 Electron 실행 바이너리를 내려받습니다. 설치가 끝나면 `npm run dev:desktop`으로도 실행할 수 있습니다.

공통 모델은 shared, 파일 처리와 트레이는 electron/main, 제한된 IPC 연결은 electron/preload, 화면은 src/components와 App.tsx에 있습니다. 전체 개발 방향은 [개발 설계서](docs/development-plan.md)에 정리되어 있습니다.
